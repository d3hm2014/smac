SMAC Website - نسخة جاهزة للنشر على GitHub Pages

طريقة النشر:
1) ارفع الملفات كلها داخل مستودع GitHub جديد
2) من Settings > Pages
3) اختر Deploy from a branch
4) اختر main و /root
5) احفظ
6) انتظر حتى يظهر الرابط

ملفات المشروع:
- index.html
- styles.css
- script.js
- Test.pdf

قبل النشر النهائي:
- استبدل info@example.com بالبريد الحقيقي
- استبدل 05XXXXXXXX برقم الجوال
- أضف المدينة
- أضف شعار الشركة الحقيقي بصيغة PNG إن توفر
- أضف المشاريع الفعلية
- أضف صور الشهادات السارية فقط

اقتراح مهم:
إذا ستستخدم الموقع أمام عملاء أو جهات، أضف دومين احترافي لاحقاً بدلاً من رابط GitHub الطويل.
